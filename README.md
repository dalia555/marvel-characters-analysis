# Marvel Characters Analysis & Classification

A data analysis and machine learning project exploring Marvel superheroes and villains using Python.

The project covers data cleaning and preprocessing, exploratory data analysis, visualization, and machine learning classification using a Random Forest model.

## Project Overview

The dataset contains information about Marvel characters, including:

- Character Name
- Real Name
- Affiliation
- Powers
- Role
- Power Level

The project explores relationships between character attributes and uses machine learning to predict a character's role based on selected features.

## Objectives

- Clean and preprocess the Marvel character dataset
- Identify and handle missing values
- Detect and remove duplicate records
- Explore patterns and relationships within the dataset
- Visualize character roles and affiliations
- Analyze the relationship between affiliation and character role
- Build a machine learning classification model
- Evaluate the model's prediction performance

---

## Data Cleaning & Preprocessing

The dataset was prepared using Python and Pandas.

The preprocessing steps included:

- Checking for missing values
- Identifying duplicate records
- Removing duplicate records
- Checking data quality and consistency
- Encoding categorical variables for machine learning
